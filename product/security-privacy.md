# 安全与隐私

## 安全边界

### 网络隔离

- 服务默认绑定本机回环地址 `127.0.0.1`，默认不暴露到局域网
- `listenHost` 可由用户在设置中修改；支持改为 `0.0.0.0` / `::` 绑定所有网卡以暴露给局域网 / WSL / 容器，属于用户显式选择，用户需自行依赖操作系统防火墙控制入站访问
- 不做 Host 头白名单校验：网络可达性与访问控制交由用户选择的 `listenHost` 与操作系统防火墙负责

### 访问控制

- 可选生成本地 Bearer Token，防止本机其他网页或程序随意调用代理
- Token 存储在系统密钥环中

## 密钥存储

- Provider API Key 不写入明文配置文件
- Provider API Key 使用 Electron `safeStorage` 或系统密钥环（macOS Keychain / Windows Credential Manager / Linux Secret Service）存储
- 配置文件中仅保存 Provider API Key 的密钥引用 ID
- 配置导入/导出时默认脱敏 Provider API Key（导出文件不含明文 API Key）
- 自定义上游代理 URL 例外：允许携带账号密码，并作为普通设置写入 SQLite 和配置导出；日志、错误与测试结果仍必须脱敏，详见 [outbound-proxy.md](./outbound-proxy.md)

## 隐私策略

### 遥测

- 默认不上报任何遥测数据
- 如未来加入匿名统计，必须默认关闭并显式征得同意

### 数据本地化

- 所有配置、密钥、日志保存在本地用户目录下的应用数据目录
- 不向任何第三方服务器上传用户数据
- 代理仅转发用户请求到用户配置的 Provider 供应商

### 请求与响应数据

- 默认保存完整请求体和响应体，以便直接进行请求调试和故障分析；用户可在设置中关闭正文记录
- 日志同时记录元数据：时间、模型、协议、供应商、状态码、耗时、错误摘要
- 客户端请求、最终响应、每次 Provider 尝试，以及协议转换前后的内容均视为敏感本地数据
- 记录前必须脱敏 Authorization、API Key、Cookie、Set-Cookie 等敏感头；正文内容完整保存在本地数据库，正文自身不视为已脱敏
- 为支持超长上下文和大体积请求，单次请求体、响应体及流式内容不设置大小限制；实现会完整读取和保存正文，可能增加内存与本地存储占用
- 用户可按保留天数清理历史日志，清理同时删除对应请求正文和远端尝试记录；关闭捕获不会自动删除已有正文
- 内容查看和导出都应明确提示可能包含提示词、文件内容和模型输出；导出默认不包含正文
- 日志内容只保存在本地应用数据目录，不上传任何第三方服务器

## 配置文件位置

| 平台 | 路径 |
|------|------|
| macOS | `~/Library/Application Support/One Switch/` |
| Windows | `%APPDATA%\One Switch\` |
| Linux | `~/.config/One Switch/` |
