# 桌面端产品形态

## 技术栈

Electron + Node + TypeScript + React/Vite

## 主要入口

### 菜单栏 / 托盘

- **macOS**：菜单栏图标
- **Windows**：系统托盘图标
- **Linux**：系统托盘（P1 完善）

### 菜单快捷区

- 服务运行状态（运行中 / 已暂停 / 异常）
- 当前监听地址（一键复制 Base URL）
- 暂停 / 恢复代理
- 打开控制台
- 退出应用

### 图标状态

| 颜色 | 含义 |
|------|------|
| 绿色 | 全部正常 |
| 黄色 | 部分降级（部分供应商冷却或禁用） |
| 红色 | 全部不可用 |

## 控制台页面

### 概览页

- 服务状态
- 今日请求数
- 失败切换次数
- 各供应商健康状态（连续失败、冷却状态、最近成功）
- 快捷操作：复制 Base URL、暂停/恢复

### 供应商页

- Provider 列表（名称、状态、连续失败、冷却状态）
- 新增 / 编辑 / 删除 / 启用禁用 Provider
- 配置认证方式、超时时间

### 模型配置页

MVP 为单模型模式，只有一个默认逻辑模型，页面直接展示该模型的绑定管理：

- 当前模型名称（固定为 `default`，不可修改）
- 绑定列表（协议类型、上游 URL、上游模型 ID、Provider、优先级、启用状态）
- 新增 / 编辑 / 删除绑定
- 拖拽调整绑定优先级

> 架构上支持多逻辑模型，MVP 仅在 UI 层隐藏多模型管理入口。未来扩展时直接增加模型列表和切换即可。

### 请求日志页

- 最近请求列表（时间、逻辑模型、协议、最终供应商、状态码、耗时）
- 查看某次请求的详细尝试过程（每个候选绑定的结果）
- 筛选：按模型、协议、供应商、状态、时间范围

### 设置页

- 监听地址与端口
- 开机自启
- 本地访问 Token（可选）
- 日志保留策略
- 配置导入 / 导出
- 关于

## 用户流程

### 首次使用

1. 启动应用，菜单栏/托盘出现图标
2. 引导添加第一个 Provider（名称、API Key、超时）
3. 在模型配置页添加绑定（选择协议、填入上游 URL 和上游模型 ID、选择 Provider）
4. 可继续添加多个绑定，拖拽调整优先级
5. 一键复制本地 Base URL
6. 在 AI 工具中配置 Base URL（model 字段可填任意值，代理会自动替换为上游模型 ID）
7. 发送测试请求，控制台显示路由和尝试过程

### 日常使用

1. 应用在后台运行，可选开机自启
2. 菜单栏图标颜色反映整体健康状态
3. 临时禁用某个供应商或调整优先级
4. 查看请求日志了解每次请求经过了哪些供应商、在哪里失败、最终由谁成功
