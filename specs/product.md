# 产品定位

## 目标用户

拥有多个大模型 API 渠道、同时使用多个 AI 工具的个人开发者。

## 核心价值

- **一次配置，多工具复用**：所有 AI 工具只接一个本地地址，不用在每个工具里重复配置多个供应商。
- **故障自动切换**：某个渠道挂了、额度用完了、返回错误了，代理自动切到下一个，用户无感。
- **统一模型名**：客户端只认虚拟模型名，真实供应商由代理管理，切换供应商不影响工具配置。
- **纯本地**：配置、密钥、日志全部保存在本地，不上传任何数据。
- **可调试**：可选记录请求、响应及协议转换前后内容，并在日志详情中查看完整链路。

## 非目标

- 不做云同步、不做账号体系
- 不做团队协作、不做多用户
- 不做模型推理本身
- 跨协议报文转换仅作为可选的端点绑定级开关（默认关闭），不是默认行为
- 不做系统级全局代理（推荐用户在各工具中单独配置 Base URL）

## 主要平台

- **主要**：macOS、Windows
- **次要**：Linux
