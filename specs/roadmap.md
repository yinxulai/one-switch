# 版本规划与验收标准

## MVP（P0）

### 范围

- Mac / Windows 菜单栏应用
- 本地 HTTP 代理，支持非流式和流式透传
- 根据请求 path 自动识别协议（openai / anthropic / gemini / custom）
- 本地 `/v1/models` 服务接口
- Provider 增删改查、密钥安全存储、空闲超时配置
- 自动切换队列：一个有序队列，每个队列项含协议 + 上游 URL + 上游模型 ID + Provider
- 协议感知路由：从队列中筛选协议匹配的项，按顺序尝试；请求 model 字段自动替换为当前队列项的上游模型 ID
- 网络错误、超时、429/5xx、401/403、模型不存在时自动切换到队列中下一个可用项
- 手动切换：用户可指定当前使用哪个队列项，新请求立即生效，进行中请求不中断
- Provider 冷却与基础健康状态
- 请求日志
- 服务开关、端口配置、开机自启
- 配置导入导出（密钥脱敏）

> 架构上完整支持多逻辑模型，MVP 仅在 UI 和路由入口处限定为单模型。底层数据库、数据模型、路由引擎都按多模型设计，未来扩展无需重构。

### 验收标准

#### 1. 基础代理验证

- [ ] 启动应用后，本地端口可访问
- [ ] 所有工具统一配置 Base URL 为 `http://127.0.0.1:port`，无需按协议区分
- [ ] OpenAI 工具请求 `/v1/chat/completions`，代理自动识别为 openai 协议并透传到对应绑定
- [ ] Anthropic 工具请求 `/v1/messages`，代理自动识别为 anthropic 协议并透传到对应绑定
- [ ] Gemini 工具请求 `/v1beta/models/*`，代理自动识别为 gemini 协议并透传到对应绑定
- [ ] 请求 `/v1/models` 返回包含 `default` 的单条模型列表，不透传到上游
- [ ] 流式请求能持续返回 SSE 数据，不被代理缓冲破坏

#### 2. 自动切换队列验证

- [ ] 队列中只有 openai 协议的项；通过 anthropic 协议请求时，返回"当前协议下无可用上游模型"
- [ ] 队列中同时有 openai 和 anthropic 的项；通过 openai 请求时只尝试 openai 项，通过 anthropic 请求时只尝试 anthropic 项
- [ ] 请求体中 model 字段为任意值时，转发到上游后被替换为当前队列项的 upstreamModelId
- [ ] 队列第一项失败（不可达），自动切换到第二项并成功返回

#### 3. 错误分类与自动切换验证

- [ ] 队列第一项不可达（网络错误），自动切换到第二项并成功返回
- [ ] 队列第一项返回 429 或 500，自动切换到第二项
- [ ] 队列第一项返回 401，切换并在控制台提示该 Provider 鉴权可能异常
- [ ] 上游返回 400 请求错误时，不切换，直接返回客户端错误

#### 4. 手动切换验证

- [ ] 在控制台手动切换到队列第二项，新发起的请求从第二项开始尝试
- [ ] 手动切换时，正在进行的流式请求不中断，继续使用原上游模型完成
- [ ] 手动切换到的上游模型失败后，仍按队列顺序自动往下切换
- [ ] 手动切换不改变队列的优先级顺序
- [ ] 重启应用后，当前手动指定的上游模型重置为队列第一项

#### 4. 流式边界验证

- [ ] 上游在响应头前失败，自动切换
- [ ] 上游已经返回 200 和部分 SSE 后断开，不切换到其他供应商，记录失败

#### 5. 健康状态验证

- [ ] 连续失败达到阈值后供应商进入冷却，后续请求跳过它
- [ ] 冷却结束后，新请求允许再次尝试该供应商
- [ ] 成功请求后连续失败计数重置

#### 6. 安全与隐私验证

- [ ] 服务默认只监听 `127.0.0.1`
- [ ] 导出配置时 API Key 已脱敏
- [ ] 本地日志中不出现完整请求体、响应体或明文密钥
- [ ] 关闭应用后代理端口释放
- [ ] 开机自启设置生效

#### 7. 跨平台验证

- [ ] macOS 菜单栏图标、菜单和控制台可用
- [ ] Windows 托盘图标、菜单和控制台可用

## P1

### 范围

- Linux 打包与托盘体验完善
- 手动额度阈值与用量统计
- 供应商测试连接能力
- 更细粒度的错误切换策略配置
- 请求 ID、日志筛选、日志导出
- 可选本地访问 Token

## P2

### 范围

- 多逻辑模型支持（模型列表、模型别名、`auto` 聚合模型）
- 更多协议路径预设（Ollama 本地、OpenRouter、Azure 等）
- 按延迟、成功率、权重或成本的智能路由
- Token / 费用统计（按协议解析用量，不做报文转换）
- 主动健康探测
- 多配置 Profile
- 本地 CLI 或无头模式
