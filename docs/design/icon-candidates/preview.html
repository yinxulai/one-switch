One Switch — 图标改版候选

结论（已定稿）：标志就用 闪电 `concept-bolt.svg`，已写入 packages/console/public/icon.svg；双刃 `blades-duotone.svg`（冷色霓虹）作为延续保留， 放在 docs/design/brand/icon-alt-blades.svg。 位图（打包 png / ico、托盘、文档导出）统一由 pnpm icons 从那个矢量源派生，不用手导。

这一页是探索过程的历史记录，按时间顺序排列，不再代表当前状态。 每行都是同一套尺寸阶梯（48 / 32 / 24 / 16）加浅/深底对照， 16px 能不能认得出来是主要判断标准。 为什么最后选了闪电而不是双刃：双刃的基因靠两条细刃的咬合， 到 16px 就糊成一块；闪电只有一块剪影，小尺寸下轮廓最硬。

A 段Bolt 的比例与胖瘦档位；B 段 双刃 v3 的七种配色； C 段 简单形状集（闪电就出自这里）；D / E 段 更早的线条方向，已否决。 配色与形状正交：定下形状后，任何一套配色都能直接套上去。

定位原句：「把手上所有大模型渠道合成一个本地地址」、 「当前渠道挂了自动换下一个」、 「排好优先级，按顺序挑渠道」、 「什么样的请求，落到哪个渠道组」、 「渠道会挂，你的活不会停」。

A · Bolt 闪电 · 比例与胖瘦档位（已被 C 段的 concept-bolt 取代）

上一轮的「横向拉宽」方向作废：把 176 × 225 拉到 230 × 225 之后，整个图形变成「宽 ≈ 高」， 看起来就扁了——那正是被否掉的原因。
本轮改成：以 F3（高挺均衡）为基准，只把闪电两根臂收窄， 圆角一律不动。F3 的圆角来自 stroke-width: 14（≈ 7px 半径）， 所以下面 4 款瘦身版全部保持 stroke-width="14"，只改路径。

F3 · 高挺均衡 ★ 你选定的比例 bolt-f-mid.svg

形状 140 × 228，宽高比 0.61，stroke-width: 14（圆角 7px）。
控制组，下面全部以它为参照。

S1 · 收窄臂宽（高度不变）★ 已应用 bolt-slender-1.svg

F3 的两根臂从 110 收到 96 宽，高度 242 一点没动，圆角仍是 7px。
最保守的一档：只「瘦」，不「扁」。

S2 · 收窄 + 高度 ×0.88 bolt-slender-2.svg

在 S1 基础上把整体高度压到 88%（约 215），比 S1 更「扁」一点点，但仍然明显高 > 宽。

S3 · 收窄 + 高度 ×0.78 bolt-slender-3.svg

高度压到 78%（约 192），是「扁瘦」里最扁的一档。再压就会丢掉闪电的纵向冲劲。

S4 · 收得更窄（高度不变） bolt-slender-4.svg

臂宽再收到 94，比 S1 更细一档。24px 下笔画仍然清楚，但 16px 时已经接近极限。

B · 双刃 v3 · 七种配色（同一几何）

Brand 原品牌色 blades-brand.svg

只换几何、不换配色，风险最低的替换项。

Brand Vivid 品牌加亮 blades-brand-vivid.svg

品牌绿蓝之间插一档更饱和的青，屏幕上更「亮」。

Aurora 极光 blades-aurora.svg

青 → 靛 → 品红，冷调但有色相跨度。

Spectrum 光谱 blades-spectrum.svg

整条彩虹斜穿图标，最花；小尺寸下色相会互相抵消，只适合大图。

Sunset 落日 blades-sunset.svg

琥珀 → 珊瑚 → 玫红 → 紫罗兰，暖色里最抓眼的一版。

Iridescent 珠光 blades-iridescent.svg

品牌绿起手，中段转蓝紫，收在暖金 —— 仿镭射膜的干涉色。

Duotone 电光 ★ 保留作延续 blades-duotone.svg

薄荷 → 天青 → 群青 → 紫，冷色撞色最狠，深色界面上最跳。
没被选为标志（16px 下两片刃会糊在一起），但整套双刃基因只留这一版：已收到 docs/design/brand/icon-alt-blades.svg。
值得一提：没有它就没有闪电 —— concept-bolt.svg 正是把这两片刃的斜切抽成了一道连续闪电。

C · 简单形状 · 渐变 + 单块剪影（九款）

Bolt 闪电 shape-bolt.svg

单块实体闪电，无描边。16px 下最清楚的形状之一，也是九个里辨识度最高的。
代价："快 / 性能" 是到处在用的隐喻，单看不会想到代理。

Swap 双向换位 shape-swap.svg

上右、下左，⇄ 严格 180° 旋转对称。就是「Switch」这个词本身——换一个接着跑。
我的推荐：名字、动作、形状三者完全对齐，且是纯实体无细节，缩到 16px 依然清楚。

Toggle 开关 shape-toggle.svg

滑块已推到右侧、内部挖空。最贴产品名的一枚。
代价：宽高比偏扁，侧栏里占地不匀；小尺寸下内孔会变细（2px 左右）。

Forward 快进 shape-forward.svg

两个实心三角。直接对应「当前渠道挂了，自动换下一个」。
比 Chevrons 重、比 Bolt 中立；唯一风险是容易被当成「播放下一个」。

Chevrons 递进 shape-chevrons.svg

双箭头，比 Forward 轻一档，方向感最干净。
适合不想太「重」的场合，但只有 30px 的臂厚，16px 时会变细。

Turn 换道 shape-turn.svg

一根粗箭杆 90° 转弯。「从这条道换到那条道」，语义很准。
四款里唯一的非对称形，侧栏里会给一点点动感。

Plug 接入 shape-plug.svg

右侧平口的插头。「本地一个地址，插上就能用」。
最「工具」的一款，但也有点像硬件配件图标。

Badge 底板 shape-badge.svg

圆角方底板里挖出一个白闪电。唯一形状自带背景。
适合 App 图标 / 托盘 / 安装包，但不适合侧栏里的透明标记（会变成一个方块）。

Spark 星光 shape-spark.svg

四角星光，尖角略抽。和「双刃」同属非几何形，气质最接近现有图标。
代价：不够具体，很多 AI 产品在用。

D · 定位推导的方向草图（线条结构，之前一轮）

Converge 汇聚 concept-converge.svg

三条来源（不同供应商 / 账号 / 模型）收流到一个汇合节点，再出一条主干。
对应：「把所有渠道合成一个本地地址」。最贴主定位的一个，但形状偏「电路/网络」，不够「开关」。

Ladder 阶梯 concept-ladder.svg

请求沿台阶逐级往下试探，到底才出击。
对应：「排好优先级，按顺序挑渠道」+「挂了自动换下一个」。三个直角转弯在 16px 下依然清楚，最抗缩小。

Fork 分流 concept-fork.svg

一个入口、多个落点。
对应：「什么样的请求，落到哪个渠道组」（路由工作台那句话）。空处多，视觉重量偏轻，和双刃摆在一起会显得弱。

Relay 接力 concept-relay.svg

两棒相推、块状递进，第二棒接手。
对应：「当前渠道挂了，自动换下一个」。和双刃同一家族（都是斜切块），但把「交替」说成「递进」。风险是易读成通用的「快进」。

Crossing 换道 concept-crossing.svg

两条并行轨道在中间交叉换位，像铁路道岔。
对应：「自动切换到下一个渠道」。语义最准的一个，但 X 形容易被读成「错误 / 关闭」。

Stack 队列 concept-stack.svg

三条长短递减的条目 + 一个「当前生效」的实心点。
对应：「逻辑模型页的渠道队列」与优先级顺序。可直接长成托盘/任务栏用的横版，但作为透明标记略显普通。

E · 早先的三个方向

Switch 开关 concept-switch.svg

最贴名字：一枚开关，右端是「已切换」的状态。
对应：产品名本身。语义直给，但宽高比扁、题材常见。

Bolt 闪电 ★ 已定为标志 concept-bolt.svg

把双刃的「斜切」抽成一道连续闪电，轮廓最硬，16px 下最清楚。
对应：「自动切换」的动作感。代价是「快 / 性能」这种到处都在用的隐喻，容易被认成加速器——但它在这个尺寸阶梯里是唯一一个 16px 仍然成立的。

Badge 应用底板 concept-badge.svg

双刃放进圆角方底板、白色反白。
对应：「本地一个入口」的 App 实体感。适合当 App 图标 / 托盘图标，不适合当侧栏里的透明标记。
